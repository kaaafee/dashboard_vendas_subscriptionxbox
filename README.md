# 📊 Dashboard de Vendas - Xbox Cloud Gaming

Este repositório contém o projeto prático desenvolvido para o desafio da **DIO (Digital Innovation One)**. O objetivo deste projeto foi transformar dados brutos de vendas da **Xbox Cloud Gaming** (serviço de jogos em nuvem da Microsoft) em informações visuais claras, permitindo uma análise eficaz do desempenho e a tomada de decisões baseada em dados.

---

## 🎯 Perguntas de Negócio Respondidas pelo Dashboard

Para direcionar a criação do dashboard e extrair valor real dos dados, o projeto foi estruturado para responder aos seguintes questionamentos estratégicos:

1. **Qual o faturamento total de vendas de planos anuais, considerando todas as assinaturas agregadas?**
2. **Qual o faturamento total de vendas de planos anuais, separado por modalidade (com auto renovação vs. sem renovação)?**
3. **Qual foi o total de vendas de assinaturas do *EA Play*?**
4. **Qual foi o total de vendas de assinaturas do *Minecraft Season Pass*?**

---

## 🚀 Sobre o Projeto

O mercado de *cloud gaming* exige acompanhamento ágil. Esta ferramenta foi desenvolvida no **Excel** para centralizar a base de dados de assinaturas, permitindo monitorar indicadores-chave (KPIs), entender o comportamento de renovação dos usuários e cruzar dados de produtos específicos de forma automatizada e intuitiva.

---

## 🛠️ Principais Recursos e Etapas

* **🧹 Tratamento e Organização:** Limpeza e estruturação da base de dados bruta de vendas.
* **📈 Indicadores de Desempenho (KPIs):** Métricas comerciais essenciais para responder às perguntas de negócio.
* **🎨 Visualização Interativa:** Gráficos e painéis dinâmicos que facilitam a leitura do faturamento por tipo de plano e produto.
* **🎯 Insights Comerciais:** Foco em transformar números complexos em respostas claras para a gestão.

---

## 📚 O que foi Praticado

Este desafio permitiu consolidar os seguintes conceitos:
* Modelagem e estruturação de bases de dados no Excel.
* Criação de dashboards gerenciais orientados a responder **perguntas de negócio**.
* Técnicas de *Data Visualization* aplicadas ao setor de assinaturas (streaming/games).
* Fórmulas e ferramentas avançadas do Excel para cruzamento e agregação de dados.
